## Scope

Version 0.1 covers dated tests of Locus Pro, Sapiom, Catena and Crossmint Agent Checkouts. It reports positive behavior alongside evidence gaps. It is not a ranking, a comprehensive benchmark or a basis for broad industry claims.

The repository publishes insights, methods, representative observations and links to public reproduction projects. It does not publish raw evidence archives, private correspondence, credentials, unrelated raw datasets or nonpublic product plans.
